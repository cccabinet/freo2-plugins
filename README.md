# freo2-plugins
プラグインはfreo2の `plugins` フォルダ内に配置すると認識されます。
その後「プラグイン管理」からプラグインをインストールし、さらに有効化することで使用できます。

## お問い合わせ
お問い合わせフォームの入力項目を、独自のものに変更します。

「会社名」「電話番号」の入力項目を追加します。案件ごとに独自の入力項目を追加するサンプルとして作成しています。

## ギャラリー
管理画面から作品を登録し、ギャラリーとして表示します。

管理画面メニューの「ギャラリー管理」から、エントリーやページと同様に登録できます。
登録したギャラリーは、`/gallery/` にアクセスすると表示されます。

## ホーム
ホームに任意の記事をいくつでも表示できます。

管理画面メニューの「設定 → 文言設定 → トップページ」に入力したテキストがトップページに表示されます。  
このとき、特定のコードを書くことで記事が表示されます。

以下のようにすると、コードが `20260208130257` のエントリーが表示されます。
```
<entry:code=20260208130257>
```

以下のようにすると、コードが `test` のページが表示されます。
```
<page:code=test>
```

以下のようにすると、エントリーが新しいものから5件まで表示されます。
```
<entries:limit=5>
```
