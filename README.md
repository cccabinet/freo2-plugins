# freo2-plugins

[freo2](https://github.com/refirio/freo2) の機能を追加するプラグイン集です。

## 導入のしかた

プラグインはfreo2の `plugins` フォルダ内に配置すると認識されます。
その後「プラグイン管理」からプラグインをインストールし、さらに有効化することで使用できます。

- プラグインに公開すべきファイル(CSS・JavaScript など)が含まれていれば、**公開ディレクトリ内の同じパスにも置きます。**
- プラグインのバージョンが上がったときは、ファイルを差し替えると管理画面に「要アップグレード」と表示されます。プラグインの詳細画面からアップグレードしてください。
- 各プラグインの説明と設定項目は、**管理画面のプラグイン詳細画面**で確認できます。設定を持つプラグインは、その画面から設定を変更します。

> プログラムを公開ディレクトリの外に置いている場合など、置き場所の詳細は公式サイトの [設置方法](https://freo.jp/freo2/setup/) を参照してください。

## どんなプラグインがあるか

[PLUGINS.md](PLUGINS.md) を参照してください。ギャラリー、商品・注文管理、マークダウンでの本文入力、URL のリライトなどがあります。

なお、最小の実装例である `sample` プラグインは freo2 本体に同梱されています。プラグインの作り方は、公式サイトの [プラグイン](https://freo.jp/freo2/plugin/) と、本体の開発ガイド(`DEVELOPMENT.md`)を参照してください。
